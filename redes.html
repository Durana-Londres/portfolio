Configuração de roteamento inter vlans com o switch multi-layer

O roteamento inter-VLAN com switch multi-layer(camada 3) é o método moderno e eficiente de permitir a comunicação entre redes virtuais distintas dentro de uma rede local (LAN). Ele ultiliza interfaces virtuais comutadas(SVis) para rotear pacotes entre VLANs, dispensando um roteador externo. O switch age na camada 2 para comutação e na camada 3 para roteamento
A topologia é composta por: um switch multi-layer, 3 switches de camada 2.Um pc para acessar cada switch e 3 hosts normais.
VLAN10: 192.168.10.0
VLAN20: 192.168.20.0
VLAN30: 192.168.30.0
Como fazer:
Primeiro, crias as vlans no switch multilayer, porque são elas que vão separar a rede em grupos. Depois, atribuis as portas do switch a cada vlan, para que os dispositivos fiquem da rede correcta. Em seguida, crias as interfaces virtuais(SVIs), que são como portas lógicas para cada vlan, e defines um endereço IP para cada uma. Esse IP vai ser o gateway dos dispositivos daquela VLAN. Depois disso, ativas o roteamento no switch com o comando de camada 3, porque sem isso ele funciona só como switch normal. Quando ativado, ele começa a fazer o roteamento entre as VLANs. Por fim, configuras os dispositivos(computadores) usarem como gateway o IP da SVI da sua VLAN. Assim, quando um computador quiser falar com outro de outra VLAN, o switch multilayer faz o encaminhamento automaticamente.
